=======================================================================
  Zabbix Web Frontend — Deployed Successfully
=======================================================================

Namespace:  {{ .Release.Namespace }}
Version:    {{ .Values.zabbix.version }}
Image:      {{ include "zabbix-web.image" . }}

-----------------------------------------------------------------------
  1. Check Web Frontend Pods
-----------------------------------------------------------------------

  kubectl get pods -n {{ .Release.Namespace }} -l app=zabbix-web -o wide

-----------------------------------------------------------------------
  2. Get ALB Address (Zabbix Web Frontend)
-----------------------------------------------------------------------

  kubectl get ingress {{ include "zabbix-web.ingressName" . }} \
    -n {{ .Release.Namespace }} \
    -o jsonpath='{.status.loadBalancer.ingress[0].hostname}'

  ALB Routing (HTTPS — SSL terminated at ALB via ACM):
    https://<alb-or-domain>/  → Zabbix web frontend

  HTTP port 80 is automatically redirected to HTTPS 443.
  Internal cluster traffic (ALB → pods) stays on HTTP port 80.

{{- if .Values.zabbixWeb.ingress.zabbixHost }}

  Configured hostname: {{ .Values.zabbixWeb.ingress.zabbixHost }}

  To configure DNS:
    1. Copy the ALB hostname from the command above.
    2. In Route53, create an ALIAS (or CNAME) record pointing
       {{ .Values.zabbixWeb.ingress.zabbixHost }} to the ALB hostname.
{{- end }}

-----------------------------------------------------------------------
  3. Verify Service & HPA
-----------------------------------------------------------------------

  # ClusterIP Service
  kubectl get svc {{ include "zabbix-web.deploymentName" . }} -n {{ .Release.Namespace }}

{{- if .Values.zabbixWeb.autoscaling.enabled }}
  # HPA status
  kubectl get hpa {{ include "zabbix-web.hpaName" . }} -n {{ .Release.Namespace }}
{{- end }}

-----------------------------------------------------------------------
  4. Access Zabbix Web UI
-----------------------------------------------------------------------

  Default Zabbix login: Admin / zabbix

{{- if .Values.zabbixWeb.ingress.zabbixHost }}
  URL: https://{{ .Values.zabbixWeb.ingress.zabbixHost }}/
{{- end }}

-----------------------------------------------------------------------
  PREREQUISITES REMINDER
-----------------------------------------------------------------------

  This chart assumes the following already exist:

  1. Namespace: {{ .Release.Namespace }}
     kubectl create namespace {{ .Release.Namespace }}

  2. Zabbix Server must be deployed and reachable at:
     {{ include "zabbix-web.serverServiceName" . }}

  3. SSM parameters under: {{ .Values.db.ssm.path }}
     Required keys: host, port, dbname, user, password

  4. EKS Pod Identity association for ServiceAccount:
     {{ include "zabbix-web.serviceAccountName" . }}
