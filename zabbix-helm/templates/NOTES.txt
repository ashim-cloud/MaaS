=======================================================================
  Zabbix Monitoring Stack — Deployed Successfully
=======================================================================

Namespace:  {{ include "zabbix.namespace" . }}
Version:    {{ .Values.zabbix.version }}
HA Replicas: {{ .Values.zabbixServer.replicaCount }}

-----------------------------------------------------------------------
  1. Check Zabbix Server HA Status
-----------------------------------------------------------------------

  # Wait for pods to be ready
  kubectl get pods -n {{ include "zabbix.namespace" . }} -l app=zabbix-server -o wide

  # Check HA node status
  kubectl exec -n {{ include "zabbix.namespace" . }} {{ include "zabbix.serverName" . }}-0 \
    -- zabbix_server -R ha_status

  # Verify HA labels (one pod should be "active", rest "standby")
  kubectl get pods -n {{ include "zabbix.namespace" . }} -l app=zabbix-server --show-labels

-----------------------------------------------------------------------
  2. Get NLB Address (for external agent2 clients)
-----------------------------------------------------------------------

  kubectl get svc {{ include "zabbix.serverActiveServiceName" . }} \
    -n {{ include "zabbix.namespace" . }} \
    -o jsonpath='{.status.loadBalancer.ingress[0].hostname}'

  External agents should connect to this hostname on port 10051.

-----------------------------------------------------------------------
  3. Get ALB Address (Zabbix Web Frontend)
-----------------------------------------------------------------------

  kubectl get ingress {{ include "zabbix.webIngressName" . }} \
    -n {{ include "zabbix.namespace" . }} \
    -o jsonpath='{.status.loadBalancer.ingress[0].hostname}'

  Open this URL in a browser to access the Zabbix dashboard.
  Default login: Admin / zabbix

-----------------------------------------------------------------------
  4. Check Agent2 DaemonSet
-----------------------------------------------------------------------

  kubectl get pods -n {{ include "zabbix.namespace" . }} -l app=zabbix-agent2 -o wide

  # Verify hostname (should show Kubernetes node name, not pod name)
  kubectl exec -n {{ include "zabbix.namespace" . }} \
    $(kubectl get pod -n {{ include "zabbix.namespace" . }} -l app=zabbix-agent2 \
      -o jsonpath='{.items[0].metadata.name}') \
    -- zabbix_agent2 -t agent.hostname

-----------------------------------------------------------------------
  REMINDER: Database Prerequisite
-----------------------------------------------------------------------

  This chart assumes the following already exist in your RDS instance:
    - Database: {{ .Values.db.name }}
    - User: {{ .Values.db.user }} (with OWNER on the database)
    - Grants: ALL on database + schema public + CREATE on schema public

  If Zabbix Server pods are in CrashLoopBackOff, check RDS connectivity
  and verify the database/user exist.
